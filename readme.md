# TYPE TO SURVIVE

A creepy typing game that runs in the browser. You get a word, you type it before the signal dies. Miss too many or type too slow and the signal degrades, the screen glitches out, and things start happening in the corners.

Built with plain HTML, CSS, and vanilla JS. No frameworks, no build step just open `index.html`.

## How to play

Head to **[https://vividhues.itch.io/typetosurvive]** , pick the difficulty and hit TRANSMIT and word and fear will start to appear.

## Audio

Uses the Web Audio API for the ambient drone and sound effects plus three MP3 jumpscare clips that fire at random during gameplay. The mute button is in the bottom-right corner if you need it(are you scared?)

## Difficulty

- **Easy** — for kids word timer slow and signal penalties small
- **Normal** — the intended experience
- **Hard** — for beasts word timer fast and typo hurts alot
