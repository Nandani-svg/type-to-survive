# TYPE TO SURVIVE

 *Type the word. Before it types you.*

---

## What is it?

Its a horror typing game that runs right in your browser. Just click the URL and sufferrrrrrrr

You get a word on your screen. You type it before the timer bar hits zero. Every word you complete keeps the signal alive. Every miss, every typo makes the signal lose a bit.

The longer you play the longer the games gets hard and there are few suprise when u play for more than 20 sec...

Its typing. But make it scary + A lil thrill

---

## How to try it

**Easiest way — just open it:**

1. Clone this repo
2. Open `index.html` in any modern browser 
3. Pick your difficulty, hit **TRANSMIT**, and start typing

Thats it. No server, no npm install, no build step. Just one single HTML file

## Tech & tools

Built entirely with **vanilla HTML, CSS, and JavaScript** 

Stuff which took time:

- **Web Audio API** — powers the horror signal type audio in background
- **Canvas API** — handles the film grain noise and the glitch bar effects that render every frame
- **CSS animations** — handles the glitch and thw scaline which happends when u play game 
- **MP3 clips** (in `/sounds`) — three random jumpscare sound which i found on the Internet
